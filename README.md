# nas-gallery

> Working title — final project/repo name TBD.

A self-hosted photo & video gallery for your NAS.

- **Frontend:** an installable web app (PWA) — a pure website, no native app — hosted on
  GitHub Pages.
- **Backend:** a single static Go binary that runs directly on the NAS (no Docker required),
  serving your media library over an authenticated API.

Publicly reachable from anywhere; your media requires login. Designed to be a generic,
open-source solution — not a one-off tool.

**Status: under construction.** See `docs/ARCHITECTURE.md` and `docs/API_CONTRACT.md`.
